# OOP2 — Экосистема на решётке

Задание №41 по ООП.

Программа моделирует простую экосистему на клеточном поле.

Есть:
- трава;
- травоядные;
- хищники;
- энергия;
- возраст;
- движение;
- питание;
- размножение;
- смерть;
- статистика по поколениям.

## Структура

Всего 7 основных Java-файлов:

```text
model/
  Position.java
  Animal.java
  Herbivore.java
  Predator.java
  World.java

simulation/
  Simulation.java

app/
  Main.java
```

`Main` только читает данные и печатает результат.

`Simulation` содержит правила и ничего не печатает в консоль.

## ООП

`Animal` — общий абстрактный класс.

От него наследуются:

```text
Animal
├── Herbivore
└── Predator
```

Поля животных закрыты и доступны через методы.

## Как считается поколение

Метод `nextGeneration()`:

1. берёт старый `World`;
2. выращивает траву;
3. двигает животных;
4. травоядные едят траву;
5. хищники едят травоядных;
6. животные могут размножиться;
7. создаётся новый `World`.

Старый объект `World` не изменяется.

## Seed

В `Simulation` используется один объект:

```java
Random random;
```

Он создаётся один раз через `new Random(seed)`, поэтому одинаковый seed даёт одинаковый результат.

## Запуск

Открыть проект в IntelliJ IDEA как Maven-проект и запустить:

```text
src/main/java/edu/oop/ecosystem/app/Main.java
```

Программа попросит ввести:

```text
Seed:
Generations:
```

Например:

```text
42
20
```

## Тесты

Все тесты находятся в одном файле:

```text
src/test/java/edu/oop/ecosystem/SimulationTest.java
```

В нём больше 20 сценариев JUnit 5.

Запуск:

```bash
mvn test
```

Публичные методы основных классов имеют Javadoc.
