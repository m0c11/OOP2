# OOP2 — Экосистема на решётке

Задание №41 по ООП. Программа моделирует природу: растёт трава, травоядные едят её, хищники охотятся, животные стареют и размножаются.

## Как запустить

Открой папку проекта в IntelliJ IDEA как Maven-проект (JDK 17).

- Main.java — запускает графическое окно.
- GameWindow.java — рисует поле, обрабатывает кнопки, показывает статистику и события.
- ConsoleMain.java — прежний консольный вариант.

В IntelliJ открой Main.java и нажми зелёную кнопку Run рядом с методом main.

## Управление

- Старт — автоматические ходы.
- Пауза — остановка.
- Один ход — переход к следующему поколению.
- Заново — создать мир снова с указанным Seed.

По умолчанию поле 10 на 10, 20 травоядных и 5 хищников. Seed = 42, число ходов = 30. При одинаковом Seed результат повторяется.

На поле синие буквы Т — травоядные, оранжевые буквы Х — хищники. Цифры рядом показывают количество животных в клетке. Чем темнее зелёный цвет, тем больше травы. Если навести мышь на клетку, появятся точные числа.

## Классы

- Position — координаты.
- Animal — общие поля: позиция, энергия и возраст.
- Herbivore и Predator — виды животных.
- World — трава, животные и номер поколения.
- Simulation — правила движения, питания, охоты, рождения и смерти.
- Main, GameWindow и ConsoleMain — ввод и вывод, без игровой механики.

При расчёте нового поколения старый World не меняется.

## Тесты

JUnit 5 тесты находятся в файле src/test/java/edu/oop/ecosystem/SimulationTest.java.

Для запуска тестов: mvn test

Репозиторий собирается Maven с JDK 17.
